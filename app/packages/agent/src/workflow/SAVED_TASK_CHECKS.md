# 任务读取、统计尾差与识题回包兼容

2026-10-30，兼容当前v12保存记录，不修改既有数据库。

## 定位与边界

本次用户提示“保存的任务或调用结果校验失败，已拒绝恢复”。只读复现确认原任务及12条识题回执的SHA256均正确，冻结输入摘要、状态机、个人目标/分配和教师报告也一致。失败来自重算统计与保存统计的浮点尾数不同，例如8/17由0.47058823529411764变成0.4705882352941176，差约5.6e-17。原生serde_json默认解析未启用float_roundtrip，部分二进制浮点往返出现末位改变，不能据此认定文件损坏。

后续实际任务还暴露识题空占位进入SourceUnit的问题：低置信度的多个空字符串、纯横线、明确的“图片中未找到题号X的正文”等元说明仅代表缺失，不应成为题干；格式异常形成的空后备项只留诊断，最终SourceUnit不包含空题干。可靠邻题照常校验，不再因这些占位整批中断。明确的题号抬头（如已知第3题前缀“3. ”）和比例冒号字形可规范比较，但小数、比例数值、否定词与真实内容差异不合并。新失败记录附带阶段，界面说明发生在识题、提炼还是核验。

桌面与独立检查器启用serde_json的float_roundtrip，保证后续往返精度。旧数据只在派生比率/均值/标准差字段允许极小IEEE-754尾差（2*Number.EPSILON*绝对重算值），并拒绝非有限值、整数结果差异、缺失/额外字段。人数、得分、题号、答案、结构仍精确校验；原始输入、回执和数据库checksum检查不放松。全部检查通过后返回从冻结成绩重算的统计副本，不更写旧记录。

## 识题兼容

这批保存回包大多只有questions，没有全局warnings。缺失warnings解释为空数组，显式的非法warnings仍拒绝。已知题号中的单项格式错误/空的低置信度占位不再让同页其他可靠题目整批失效；空占位也不能误当作另一页上的真实重复题号。超出当前考试的附加印刷题不采纳、不顺延。仍需两次高置信度且无阻断警告的一致文字才能采用，冲突、重复题号、条件不明和真实警告继续隔离。

只读离线重放原有12条回包后，11个原题号有可靠文字，另外2个仍有警告或内容冲突。该结果不自动回写为新任务，不冒充已经提炼知识或完成听写/补练。原来的partial结果仍保留原始失败记录。

注意这是上一任务的复核结果。后续另一个失败任务的完成回包不同，离线重放后只有6题通过一致性，其他原题仍有警告/内容冲突；不能将前一任务的11题结论挪到新任务。两批都只复用本批自己的已保存回包，不以旧题干覆盖真实差异。

## 无新增花费的查看方式

全班入口的“本机历史任务 → 打开历史结果”读取原账号任务库；“离线复核已保存识题”仅调用loadResponse，重新解析保存回包，显示可靠题号与待核查题号。这个操作不领取Key、不发模型请求、不新建生成任务、不改变账本/次数，也不把原partial提升为contentReady。保存回执不足就停止，不暗中重新识题。

## 工程验证

新增统计尾差/篡改拒绝、缺全局警告、空占位/相邻有效题隔离、实际警告仍拦截及离线回执复核不调用模型的回归。Rust直接验证若干问题比例的浮点bit往返。界面覆盖历史结果读取与离线复核无新增模型调用。真实任务仅在本机只读检查，无真实资料、图像或学生信息提交GitHub。
