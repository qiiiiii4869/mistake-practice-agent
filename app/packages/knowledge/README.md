## 本次改变的提炼路径

1. 读题先识别研究对象、核心概念和任务：辨析概念、解释过程、读图取证、设计实验或遗传计算。
2. 用题干和选项的主题词检索知识卡，在写候选知识句之前提供规范命题与来源。只命中词语不等于判定选项正确，仍需确认任务相关性与适用条件。
3. 原题用于确定“本题在考什么”，知识库回答“这个概念怎样准确表达”。不再要求教材定义必须在原题逐字出现，也不把题设陌生名词和数据当默认听写内容。
4. 区分通用知识、题设模型和实验观察。用“对象＋条件＋关系＋结论”形成短、自足、可迁移的原子命题；一次只承载一个主要复习目标。
5. 听写检查核心术语、因果节点或适用条件，保留数量、方向、时期和概率分母。变式题从目标和评分依据出发，改变有效条件或证据任务。
6. 核查科学正确性、来源适用性及本题映射，保留独立解答。校验服务于知识目标，不能代替知识内容建设，也不因提高通过率接受不可靠事实。

例如，原题含“敲除后mRNA不变、蛋白分泌改变”，应先映射到“转录/翻译/分泌的证据层级”，再选择“mRNA不变不等于蛋白功能不变”等规范命题；不要求背STING名称，也不能仅凭此结果断言唯一的翻译机制。遗传题先梳理基因作用、配子、交配和筛选分母，再提炼适用规则，不背某组字母得到的偶然数值。

## 资料质量与来源

2024卷的参考解析存在局部误述，包括高倍镜调焦、轴突分支、Tal相关专有机制、重复序列计算和稳定同位素解释等。五处具体页码及处理记录在sourceIssues；未将其机械转成事实。2025卷简答只作为定位与交叉理解，不冒充教材。题面与解析不同编号以内容顺序统一，引用使用PDF物理页，不使用页面印刷序号猜测。

资料原件留在用户本机，不将两份PDF、提取全文或个人错题档案上传仓库。仓库只包含原创整理、来源指纹、章节框架和方法。新增完整教材/可信修订时，可以继续补卡并更新版本。

## 程序接线

- `biology.ts`执行本地确定性主题检索，生成含卡号、整理性质、完整命题与来源位置的证据；无命中返回空，不能伪造知识。
- 生物生成在提炼前检索，证据逐原题写入检查点，进入提炼、修复和事实核验；不同原题不借用彼此证据。
- 后续按候选知识点补检索，合并用户PDF证据；本机PDF按概念分别检索，避免把多个概念拼成一个必须逐字连续出现的长短语。
- 内置卡与用户PDF分别显示，用户无需手动导入。不会把内置卡写成“账号已导入原PDF”。PDF引用的来源名明确标注“内置整理卡”。
- 库版本并入新生物任务knowledgeRevision和分析缓存键。旧任务及回执保持可查看；更换知识依据后不继续旧未完成任务。盲填/解题请求不追加标准答案或知识卡，仍保持独立性。

本次工程检查不代表真实模型已按新方法完成全班生成；不会自动重跑已有任务或修改旧成绩与报告。
