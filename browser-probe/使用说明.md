# 全班逐题对错验证 · 0.3.3

教师手动登录后，程序自动读取任教范围内的全班逐题得分，保存“全对、全错、部分得分、未计分”四种状态。试卷照片由教师另行上传并按题号关联，此工具不读取或下载答题卡图片。

## 更新并实测

1. 到 `chrome://extensions`，在“智学网自动导出验证”卡片上点击刷新按钮。
2. 回到已登录的智学网页面，点击右上角拼图中的本扩展。
3. 浏览器会打开独立测试页，顶部显示“全班对错验证 · 0.3.3”。
4. 点“读取我的考试”，选择考试。单一任教学科和班级自动选中。
5. 点“自动读取并保存全班结果”，保持测试页和原智学网页面打开。

可看到已读取人数、成功数、没扫或无原卷人数和失败数。临时网络失败会重试一次，认证或权限失败则停止后续请求。题号或满分不一致的学生会记为失败，不会默认为无错题。

## 自动生成文件

文件在下载目录的 `zhixue-auto-export` 文件夹：

- `verification-full.json`：认证、接口状态、人数、题目数及错误统计，不包含学生姓名或标识。
- `student-class.json`：每名学生的标识、姓名、题号、得分、满分和对错状态。
  名单成绩栏标为“没扫”的学生，以及智学网官方页面判定为无原卷的学生（名单中 `hasOriginPaper` 为否；该字段缺失时排名代码为 -2 或 -3），单独列在 `unavailable_students`，不请求原卷，题目列表为空，不判对错。无原卷学生保留名单总分和排名代码，供教师核对是否缺考或手工登分。
- `diagnostic.json`：失败时点击“保存错误诊断”生成的诊断报告。

所有文件保存本机，不含密码、Cookie、会话令牌、学生作答原文或图片网址。只有浏览器确认下载完成后，页面才提示文件已保存。

## 正误规则

- 满分大于 0 且得分等于满分：全对。
- 满分大于 0 且得分为 0：全错。
- 得分介于 0 和满分之间：部分得分。
- 满分为 0：未计分，不判定对错。

小问仅返回得分而缺少满分时，保留得分，不推断小问正误。整题部分得分不等于所有小问都错误。

## 验证状态

0.2 版已实测取得 50 人名单，以及 3 名学生各 24 题的样本。0.3 版实测处理 50 人，其中 49 人各 24 题成功，最后一人的原卷 HTML 无法解析。0.3.1 增加了同一教师权限下的结构化逐题接口补读。0.3.2 将名单成绩栏明确标为“没扫”的学生单独记录，不再算作失败；总分为 0 不视为没扫，请求失败也不会归为没扫。0.3.2 实测时，第 50 名学生的成绩栏是数字而不是“没扫”，但名单标明无原卷、排名为负，原卷页和结构化接口都没有逐题记录。0.3.3 按官方班级成绩页的“查看原卷”规则，把这类学生记为“无原卷”，不再记为失败。33 项核心测试通过。2026-10-25 用 0.3.3 实测全班 50 人：49 人导出、1 人无原卷、0 人失败，审计脚本核对通过。补读仍然只处理得分和正误，不读取图片。

权限仍只有 `activeTab`、`scripting`、`downloads`，未增加全站访问权限。打开测试页后，程序仅在用户点击扩展的那个智学网标签页运行。后台启动器只负责打开独立测试页。

接口依据：智学网官方发布的报告列表和班级成绩前端代码，以及 `anwenhu/zhixuewang-python` 教师原卷解析实现。
